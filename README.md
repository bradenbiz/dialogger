# Dialogger

for clear-cut conversations

A Next.js app for mapping a conversation as a tree of questions, ideas,
decisions, pros and cons.

## Run it

```bash
pnpm install
pnpm dev
```

Then open http://localhost:3000. `.env.example` lists the Vercel KV variables
the view counter uses. The counter is turned off, so the app runs without them.
